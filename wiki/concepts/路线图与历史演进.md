## TL;DR

v1.0 Bazel 时代（8 阶段）→ v2.0 Python 迁移（配置引擎 + 构建引擎 + App 打包 + 构建优化 + 刷写增强 + Recovery 系统）；当前进行中：Allwinner A733 平台落地。

## 关键里程碑（时间序）

- **v1.0 Bazel Phase 0-7**：Docker 构建环境、aarch64 交叉编译、三层配置体系、内核/Bootloader/Rootfs 全链路、CLI 脚手架，支持 4 块 RK3566 板子
- **v2.0 Python 迁移**：删除全部 Bazel/Starlark（47 个文件）与 shell 构建脚本（6 个）；引入 `config/merge.py`（deep_merge + resolve_conditions）、`builder/engine.py`（依赖图 + 内容哈希）、product/variant、分区表系统
- **App 打包系统**：`app.yaml` + Pure Python deb 引擎、6 种构建系统、4 种 App 类型、脚手架生成器，466 个单元测试
- **构建优化**：rootfs 两阶段缓存（跳过 5-15 min apt）、App 源码哈希修复、`_hash_directory` 工具方法
- **刷写增强**：纯 Python `flash.py` 统一刷写，消除偏移硬编码，`FlashStrategy` 抽象 + Rockchip 实现
- **Recovery 系统**：独立分区 + 双 extlinux + boot-once + ADB transport（commit 33bc2c2 实现 boot-once）

## 当前节点

Allwinner A733 平台策略类实现中（`builder/platforms/allwinnera733/`）。
