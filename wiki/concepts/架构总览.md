## TL;DR

flange 是基于 ubuntu-base 的嵌入式 Linux 构建框架，定位类似 Buildroot/Yocto 但更可预期。核心理念：Docker 内构建、宿主机刷写、Python 驱动、内容哈希增量。

## 关键设计要点

- **Docker 容器构建 + 宿主机刷写分离**：编译在容器内保证一致性，刷写在宿主机通过 USB 执行平台工具
- **Python 构建引擎**：`builder/engine.py` 管理组件依赖图，基于内容哈希自动推断增量构建范围
- **多平台支持**：Rockchip `upgrade_tool`、Allwinner `sunxi-fel/PhoenixSuit`、Qualcomm `QDL/QFIL`（计划中，未实现）；各平台通过策略子类注入
- **打样不等于硬编码**：以 RK3566 Radxa Zero 3W 验证，但框架层必须平台无关
- **product/variant 配置**：`lunch <board>-<product>-<variant>` 选择目标，条件标记动态叠加

## 数据流

```
源码 → builder/platforms/<vendor>/ 策略类
     → Docker 内编译（内核/bootloader/rootfs/recovery）
     → .build/target/<board>/<product>/<variant>/
     → flash-config.json
     → 宿主机 flange flash → upgrade_tool / sunxi-fel
     → 目标设备分区写入
```
