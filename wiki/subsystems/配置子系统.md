## TL;DR

`builder/config/` 负责发现 `config.jsonnet`、按固定层级求值、规范化动态包内容，并在构建前校验唯一的 canonical JSON 契约。

## 关键设计要点

- **jsonnet.py**：以 rootfs → 公共 overlay → platform → SoC → board 的固定顺序组合配置；`product` 与 `variant` 通过 extVar 输入。
- **registry.py**：发现 board/platform/SoC 并提供 `resolve_config()`；不加载配置 Python 模块。
- **canonical.py**：提供 `architecture.*` 与 `kernel.device_tree.*` 的无 alias 访问器。
- **apps.py / packages.py**：在求值边界规范化外部 App，并展开硬件特性包。
- **validate.py**：拒绝未知字段、旧 alias、未求值操作键、无校验下载和悬空 source 引用。
- **query.py**：枚举并解析 `<board>-<product>-<variant>` lunch target。
