## TL;DR

只创建 `components/board/<name>/config.py`（可选 overlay / patches），**不改框架代码**。

## 流程步骤

**1. 创建 board 目录**

```
components/board/<board-name>/
├── config.py          # 必须
├── overlays/          # 可选：board 私有 DT overlay 源文件（.dts/.dtso）
├── overlay/           # 可选：覆盖 rootfs 文件
└── patches/           # 可选：内核/u-boot 补丁
```

**2. 编写 config.py**

参考 `components/board/radxa-zero3w/config.py`，必填字段：

```python
BOARD = {
    "board":    "<board-name>",
    "soc":      "<soc-id>",        # 如 rk3566
    "platform": "<platform>",      # 如 rockchip / allwinnera733
    "kernel": {
        "dts": "<dts-name>",       # 设备树文件名（不含后缀）
    },
    # 可选：partition / flash_tool / product / variant 覆盖
}
```

字段越少越好——未声明的字段由[[三层继承]]从 platform → product → board 层自动补全。

**Board 私有 overlay**：`components/board/<board>/dtso/` 下放 `.dts`/`.dtso` 文件，在 `config.py` 的 `boot.board_overlays` 列表中声明 `.dtbo` 文件名。构建时由 device-tree-overlay 组件自动编译（`cpp + dtc`）。见 [[新增平台支持]] 中 Out-of-Tree 模块章节。

**3. 测试**

```bash
lunch <board-name>-<product>-<variant>
flange build
flange flash
```

## 违反"只改 config"的信号

若新增板子需要修改 `builder/platforms/` 或 `builder/engine.py` 才能工作，说明框架抽象不足——应先在框架层做重构，而不是在 board config 中打补丁。

## 参考示例

`components/board/` 下已有：`radxa-zero3w`、`orangepi-cm4`、`tspi-rk3566`，均是只含 `config.py` 的轻量板级配置。
