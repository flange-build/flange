# flange Wiki

这里保存 flange 的概念地图、代码入口、板卡适配摘要和硬件专题。
第一次使用请读[初学指南](../docs/first-steps.md)；按主题查阅从[知识库索引](index.md)进入。

- [开发指南](../docs/development-guide.md)：命令与工作区操作。
- [维护指南](../docs/maintenance-guide.md)：定位构建、缓存和设备问题。
- [扩展指南](../docs/extension-guide.md)：新增 App、Package、板卡和平台。
- [板卡索引](boards/index.md)：具体硬件、介质和历史验证范围。

规范以 [ProjectSpec](../ProjectSpec.md) 为准，架构契约以[构建系统设计](../docs/build-system-design.md)
和 [App 架构](../docs/app-architecture.md)为准。wiki 负责连接这些文档与代码，
历史实验和旧平台记录不能覆盖当前 CLI 或配置 schema。
