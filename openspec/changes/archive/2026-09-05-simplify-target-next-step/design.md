## Context

目标选择完成后，`builder/commands.py` 已统一输出目标摘要和下一步提示，
命令片段通过现有语义颜色接口呈现。本次只需调整这行提示及对应文档。

## Goals / Non-Goals

**目标：** 成功选择目标后显示 `flange build 或 flange plan`，分别指向系统构建与计划预览。

**非目标：** 不调整命令参数、目标持久化、JSON（结构化数据格式）结果或 App 开发流程。

## Decisions

- 在已有提示位置替换命令文字，继续由现有命令语义角色着色；无需新增提示分支或公共接口。
- 使用不带组件名的 `build` 和 `plan`，与两者默认面向系统 image（完整镜像）的行为一致。
- 终端图片继续从临时工作区的真实 PTY（伪终端）输出生成，使截图与当前提示一致。

## Risks / Trade-offs

- 提示文本与截图可能失步 → 同步更新 CLI 体验文档和真实终端图片，检查生成记录中的完整提示。
- 完整构建不属于文案验证 → 使用临时工作区验证目标选择输出，并运行已有测试，不执行编译或刷写。
