## Context

首页现有大图与解释段落占用首屏，具体板型只能通过 Wiki 查找。仓库目前有 19 个板卡配置，分属四个厂商平台。

## Goals / Non-Goals

目标：提供三种可对比的品牌方向，让读者先识别项目用途与板卡，再进入操作。
非目标：不修改命令接口、硬件配置、验收结论，不将 Logo 候选作为完整品牌规范。

## Decisions

- Logo 使用内置 imagegen 探索与润色；用户最终选定 C2「石墨 × 橙」，保存为唯一正式资源 `docs/assets/flange-logo.png`。按用户要求删除其他候选、对照页与旧版 Logo。
- 首页使用 GitHub 原生 Markdown（轻量标记语言）与简单图片标签。板卡信息使用可搜索、可点击的文字表格，不烘焙为图片。
- 按 Rockchip、Amlogic、Allwinner、Qualcomm 分组列出板卡和 SoC，并链接板卡页。总数以板卡配置目录核对。
- 快速开始以 `source envsetup.sh → lunch → flange build → flange flash` 为主线，说明首次 Docker 镜像准备与刷写前提；无设备计划作为补充入口。
- 不使用统一绿色“已验证”徽章；配置存在与硬件验收分开说明，明确 VIM3 与 Radxa Zero 的待验收范围。

- 分层与架构采用可编辑 SVG 图片，分别展示仓库分工、扩展层组合、配置求值，以及宿主配置、Docker 构建、工作区产物、宿主刷写和设备边界。保留图片替代文本与详细指南入口。

## Risks / Trade-offs

- 板卡清单可能随新增配置过时 → 修改时核对目录、型号与链接，记录本轮检查日期；同步修正旧板卡索引中 ROCK 5C Lite 的芯片标注为 RK3582。
- 图像生成输出未必是纯色矢量 → 定位为候选位图，当前交付选定 PNG（位图），后续可制作矢量规范。
- 页面在窄屏和暗色主题下可能拥挤 → 控制 Logo 宽度与表格列数，检查实际渲染。
