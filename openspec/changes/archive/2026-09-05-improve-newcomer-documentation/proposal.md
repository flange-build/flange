## Why

当前文档已经描述 v3 的能力，但默认读者理解嵌入式术语及仓库分层。新人难以选择第一条可完成的路径，
Wiki 中的旧入口和重复架构描述又会打断学习，需要按读者的任务重新组织整个文档系统。

## What Changes

- 由不带项目对话背景的子 agent 从 README 开始试读并直接改进入门路径。
- README 提供定位、最少概念和分流，新手指南提供无需设备的第一次成功及后续升级路径。
- 增加维护与扩展指南，用源码地图、决策图和经核验的示例说明改哪里、如何验证、如何同步。
- 清理 Wiki 的过时核心概念、命令和路径；主导航采用 GitHub 可读链接，专题保留明确适用范围。
- 同步 ProjectSpec、贡献说明、开发指南及文档能力规格，并检查命令、链接、配置与图示。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `developer-documentation`: 明确新手学习路径、使用/维护/扩展分工、图文可访问性和可执行示例要求。

## Impact

仅修改 README、ProjectSpec、CONTRIBUTING、docs、wiki 和 OpenSpec 文档，不改变构建运行逻辑。

## 非目标

- 不假定拥有某块开发板，不执行真实刷写或声称新增硬件验收。
- 不把全部专题压缩成一个教程，不重新叙述已有证据不足的硬件接线、供电或启动参数。
- 不以主观易读评价替代命令、配置、链接与当前代码的交叉验证。
