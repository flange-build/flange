# Cubie A7A 的 E3 触摸与供电故障

适用范围：[Cubie A7A](../boards/radxa-cubie-a7a.md) 的 `meizu-e3-bringup` 产品、
魅族 E3 模组上的 sec_ts（I2C `0x48`）与 SGM37604A 背光（`0x36`），两者共用 twi2。
当前不能声明这套触摸组合稳定可用。

## 已观察到的故障

较早测试曾读出触摸坐标，后续启动中出现 `0x48` 不应答、INT/PD18 持续为低，
约 1748 次/秒的中断及 I2C 超时，同时影响背光。稳态电压测量为 3.3 V / 1.8 V，
但没有提供启动瞬态的示波器证据，不能仅由稳态正常推断电源上升过程正常。

卸载触摸驱动后 I2C 仍未发现 `0x48`；复位、INT 上拉、切换 DMA、延迟加载、
重新上电与关闭背光等尝试未恢复触摸。现象提示应继续检查模组供电、复位及总线电气状态，
不应只靠修改触摸坐标或中断号处理。

## 处理边界

记录中的 IRQ 限速至 100 Hz、跳过重复 I2C 访问及限制 CPU 亲和性的临时措施曾恢复背光、
减少 engine timeout，但触摸仍不工作。这是降低整机影响的措施，不是触摸修复，
不能默认认为所有配置已包含或验证该改动。

启动浪涌欠压是现有排查方向，尚无可复核的瞬态测量和硬件修改后验收结果。
不保留无法追溯的外板故障比例或“加固定容量电容即可根治”的结论。
硬件处理应先确认实际供电轨、电源顺序和复位波形，再验证修复后的冷启动、热启动、触摸及背光。

驱动与 overlay 配置见[魅族 E3 功能包](meizu-e3-panel.md)。
